# E-mails transacionais do DOSE (Supabase Auth)
Templates em HTML, escuro, wordmark DOSE., um botão. Variáveis do Supabase: `{{ .ConfirmationURL }}`, `{{ .NewEmail }}`.
Só podem ser aplicados depois de configurar SMTP próprio (Supabase → Authentication → Emails → SMTP Settings).
Assuntos sugeridos: "Confirme seu e-mail · DOSE" · "Redefinir senha · DOSE" · "Seu link de acesso · DOSE" · "Confirme a troca de e-mail · DOSE".
